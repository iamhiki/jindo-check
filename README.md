# 진도 체크판

베이스 레슨 숙제를 매일 얼마나 연습했는지 캐릭터 도장을 색칠하며 기록하는 웹앱이에요.
**https://iamhiki.github.io/jindo-check/** · 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 할 수 있는 것

**학생**
- 레슨에서 받은 숙제마다 하루 목표 세트를 정하고, 1세트 할 때마다 캐릭터 얼굴을 하나씩 색칠해요. 다 칠하면 합격 도장이 찍혀요.
- 잘못 눌렀으면 바로 뜨는 **되돌리기**로 취소해요.
- 달력에 레슨 날짜를 적으면 다음 레슨까지 D-day를 세어줘요. 캘린더 앱에도 넣을 수 있어요.
- **기록** 탭에서 연속 연습일, 이번 주 세트 수, 연습한 날마다 도장이 찍히는 **수련 도장판**을 봐요.
- 로그인하면 아이폰, 아이패드, 컴퓨터 어디서든 같은 기록을 봐요.

**선생님** (앱이 없어도 돼요)
- 학생이 **기록 탭 → 선생님께 보여주기**에서 만든 링크를 카카오톡이나 인스타 DM으로 받아요.
- 링크를 누르면 로그인 없이 그 학생의 최근 7일 연습량, 숙제별 목표 달성, 수련 도장판이 보여요. 학생이 색칠할 때마다 저절로 바뀌어요.
- 그 화면에서 **한마디**를 남기면 학생 앱 첫 화면에 바로 떠요.
- 학생은 인스타 스토리용 이미지나 요약 글로도 보낼 수 있어요.
- 선생님도 앱을 쓰면 **설정 → 선생님 모드**를 켜고 **학생** 탭에서 여러 학생을 한눈에 봐요.

자세한 사용법은 아래 [8. 선생님과 연습 기록 공유하기](#8-선생님과-연습-기록-공유하기)를 보세요.

> **업데이트 후 꼭 한 번:** 공유 기능 때문에 `firestore.rules`가 바뀌었어요. Firebase 콘솔 → Firestore Database → **규칙** 탭에 새 내용을 붙여넣고 **게시**해야 공유 링크가 열려요.

# 사이트 여는 방법

> **GitHub Pages로 올려둔 경우** (저장소: https://github.com/iamhiki/jindo-check)
> 사이트 주소는 **https://iamhiki.github.io/jindo-check/** 예요. 아래 1~3-1단계(Firebase 만들기, 초대 코드)만 하고,
> - 4단계: `firebase-config.js`는 GitHub 저장소 화면에서 파일을 열고 연필(✏️) 버튼 → 값 붙여넣기 → **Commit changes**로 저장해요. 1~2분 뒤 사이트에 반영돼요.
> - 5단계(Netlify)는 건너뛰어요.
> - 6단계: 승인된 도메인에 `iamhiki.github.io` 를 추가해요.

다 하면 `https://내사이트.netlify.app` 같은 주소가 생겨요. 친구들은 그 주소로 들어와서 각자 회원가입하고, 자기 기록만 보고 쓰게 돼요.
돈은 들지 않아요. Firebase 무료 요금제(Spark)와 Netlify 무료 요금제로 충분해요.

준비물: 구글 계정, 이 폴더(`site`)

---

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 만들기** → 이름(예: `bass-check`) 입력 → Google 애널리틱스는 **꺼도 돼요** → 만들기.

## 2. 로그인 방법 켜기

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**.
2. **로그인 방법** 탭에서
   - **이메일/비밀번호** → 사용 설정 → 저장
   - **Google** → 사용 설정 → 프로젝트 지원 이메일 선택 → 저장

## 3. 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)** 추천 → **프로덕션 모드**로 시작.
3. 만들어지면 **규칙** 탭을 눌러서, 안에 있는 내용을 전부 지우고 이 폴더의 `firestore.rules` 내용을 붙여넣은 뒤 **게시**.
   - 이 규칙 덕분에 **초대 코드를 넣은 사람만** 쓸 수 있고, 각자 자기 기록만 읽고 쓸 수 있어요. 꼭 해주세요.

## 3-1. 초대 코드 만들기

초대 코드가 없으면 아무도 가입할 수 없어요. 코드 하나를 먼저 만들어 두세요.

1. Firestore Database → **데이터** 탭 → **컬렉션 시작**
2. 컬렉션 ID: `invites`
3. 문서 ID: **초대 코드로 쓸 글자** (예: `hunter2026`) ← 이게 곧 초대 코드예요
   - 대문자·소문자를 구분해요. 띄어쓰기와 `/`는 쓰지 마세요.
4. 필드는 아무거나 하나 넣으면 돼요 (예: 필드 `memo`, 값 `친구들용`) → **저장**
5. 친구들에게 링크와 함께 이 코드를 알려주세요.

- **코드 바꾸기**: `invites`에 새 문서를 만들고, 예전 코드 문서를 삭제하면 돼요. 이미 가입한 사람은 계속 쓸 수 있어요.
- **코드 여러 개**: 문서를 여러 개 만들면 그 코드들 모두 쓸 수 있어요. (예: 반마다 다른 코드)
- **누가 어떤 코드로 들어왔는지**: `members` 컬렉션에서 사람별로 `code`, `joinedAt`(가입일)을 볼 수 있어요.
- 초대 코드 목록은 앱에서 읽을 수 없게 막혀 있어요. 콘솔에서만 보여요.

## 4. 사이트에 Firebase 연결하기

1. 왼쪽 위 **톱니바퀴 → 프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘 **`</>`** 클릭.
2. 앱 닉네임(예: `진도 체크판`) 입력 → **앱 등록** (Firebase 호스팅 체크는 안 해도 돼요).
3. 화면에 나오는 `firebaseConfig = { apiKey: "...", ... }` 값을 복사해요.
4. 이 폴더의 `firebase-config.js`를 메모장/텍스트편집기로 열고, 따옴표 안에 각 값을 붙여넣고 저장해요.

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "bass-check.firebaseapp.com",
  projectId: "bass-check",
  storageBucket: "bass-check.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

> apiKey는 비밀번호가 아니에요. 어느 프로젝트인지 알려주는 값이라 사이트에 들어가 있어도 괜찮아요. 기록은 3단계의 규칙이 지켜줘요.

## 5. 사이트 올리기 (Netlify Drop, 제일 쉬운 방법)

1. https://app.netlify.com/drop 에 들어가서 가입(구글 계정 가능).
2. `site` 폴더를 통째로 화면에 **끌어다 놓기**.
3. 잠깐 기다리면 `https://어쩌구.netlify.app` 주소가 생겨요.
   - **Site configuration → Change site name**에서 주소 앞부분을 원하는 이름으로 바꿀 수 있어요.
4. 나중에 파일을 고치면 **Deploys** 탭에서 폴더를 다시 끌어다 놓으면 업데이트돼요.

## 6. 사이트 주소를 Firebase에 등록하기 (안 하면 로그인이 막혀요)

1. Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인** → **도메인 추가**.
2. 5단계에서 받은 주소를 `https://` 없이 넣어요. 예: `bass-check.netlify.app`

## 7. 휴대폰에서 앱처럼 쓰기

- **아이폰·아이패드**: 사파리로 사이트 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: 크롬으로 열기 → 메뉴(⋮) → **홈 화면에 추가**

처음 한 번 닉네임을 정해 회원가입(또는 Google 로그인)하면, 같은 계정으로 들어간 기기끼리 기록이 맞춰져요. 하루에 한 번 헌터 라이선스 모양 환영 카드가 떠요.

## 8. 선생님과 연습 기록 공유하기

> **이 기능을 처음 켤 때 꼭 한 번:** `firestore.rules`가 바뀌었어요. 3단계처럼 Firebase 콘솔 → Firestore Database → **규칙** 탭에 새 `firestore.rules` 내용을 전부 붙여넣고 **게시**해 주세요. 안 하면 공유 링크가 열리지 않아요.

### 선생님이 앱을 안 쓰는 경우 (카톡·인스타로 받기)

1. 학생: **기록** 탭 → **선생님께 보여주기** → **공유 링크 만들기**
2. **카카오톡으로 보내기**를 누르거나, 링크를 복사해서 인스타 DM 등으로 선생님께 보내요. **한 번만 보내면 돼요.**
3. 선생님: 받은 링크를 누르면 **로그인 없이** 그 학생의 연습 기록이 보여요.
   - 최근 7일 세트 수, 연습한 날, 연속 연습, 지난 레슨 이후 며칠 연습했는지
   - 숙제별 최근 14일 (목표를 채운 날은 진한 점)
   - 최근 5주 수련 도장판 (연습한 날마다 캐릭터 도장, 목표를 다 채운 날은 합격 표시)
4. 학생이 색칠할 때마다 같은 링크의 내용이 저절로 바뀌어요. 선생님은 링크를 즐겨찾기해 두고 아무 때나 열어보면 돼요.
5. 선생님은 그 화면 아래에 **한마디**를 남길 수 있어요. 학생 앱 첫 화면에 바로 떠요.

그 밖의 보내기:
- **인스타 스토리 이미지**: 최근 7일 기록을 1080×1920 이미지로 만들어요. 공유하기 → 인스타그램을 고르면 스토리나 DM으로 올라가요.
- **다른 앱으로 보내기**: 요약 글 + 링크를 휴대폰 공유창으로 보내요. 공유창이 없는 컴퓨터에서는 복사돼요.
- **로그인 없이 쓰는 모드**(firebase-config.js가 비어 있을 때)에서는 실시간 링크 대신 요약 글과 이미지만 보낼 수 있어요.

공유를 그만두려면 **공유 끄기**, 링크가 다른 사람에게 퍼졌으면 **링크 새로 만들기**를 눌러요. 그러면 예전 링크는 더 이상 열리지 않아요.

**선생님에게 보이는 것**: 닉네임, 숙제 이름·메모·하루 목표, 날짜별 세트 수(최근 120일), 레슨 날짜. 이메일은 보이지 않아요. 링크를 아는 사람은 누구나 볼 수 있으니 단톡방 같은 곳에는 올리지 마세요.

### 선생님도 앱을 쓰는 경우 (여러 학생 한눈에 보기)

1. 선생님도 초대 코드로 가입해요.
2. **설정** → **선생님 모드** 켜기 → 아래에 **학생** 탭이 생겨요.
3. 학생이 보낸 링크를 **학생** 탭에 붙여넣거나, 링크를 연 화면에서 **내 학생으로 추가**를 눌러요.
4. 학생마다 최근 7일 세트 수, 마지막 연습일, 연속 연습이 실시간으로 보여요. 3일 넘게 연습하지 않은 학생은 빨간 글씨로 표시돼요. 카드를 누르면 자세한 기록과 한마디 칸이 열려요.

### (선택) 카카오톡 공유 카드 켜기

키가 없어도 **카카오톡으로 보내기**는 휴대폰 공유창을 열어서 카톡으로 보낼 수 있어요. 키를 넣으면 제목, 기록 요약, **연습 기록 보기** 버튼이 붙은 카톡 카드로 보내져요.

1. https://developers.kakao.com 에 로그인 → **내 애플리케이션** → **애플리케이션 추가하기** (이름 예: `진도 체크판`)
2. **앱 설정 → 플랫폼 → Web 플랫폼 등록** → 사이트 도메인에 `https://iamhiki.github.io` 추가 (Netlify를 쓰면 그 주소)
3. **앱 키**에서 **JavaScript 키**를 복사해요.
4. `firebase-config.js` 맨 아래 `window.KAKAO_JS_KEY = "";` 따옴표 안에 붙여넣고 저장해요.

> JavaScript 키도 비밀번호가 아니에요. 2단계에서 등록한 도메인에서만 쓸 수 있어요.

> 카카오톡이 자동으로 매주 메시지를 보내게 하려면(알림톡) 사업자 등록과 서버가 필요해서 이 사이트에는 넣지 않았어요. 대신 링크 하나로 선생님이 언제든 최신 기록을 볼 수 있게 했어요.

## 고친 버전을 다시 올리기 (업데이트)

새 압축 파일을 받을 때마다 이렇게 해요.

1. 새 압축을 풀어요.
2. **중요:** 예전 폴더에 있던 **내 `firebase-config.js`** 를 새 폴더에 덮어써요.
   새 압축 안의 `firebase-config.js` 는 빈칸이라서, 그대로 올리면 로그인이 사라지고 "이 기기에만 저장" 모드가 돼요.
   (`firestore.rules` 가 바뀌었다고 안내받은 경우에만 3단계처럼 규칙도 다시 붙여넣어요.)
3. Netlify에 들어가서 내 사이트 → **Deploys** 탭 → 아래쪽 "Drag and drop your site output folder here" 칸에 새 `site` 폴더를 끌어다 놓아요.
4. 1분쯤 뒤 사이트를 새로고침하면 바뀐 버전이 나와요. 휴대폰 홈 화면 앱은 한 번 껐다 켜면 돼요.

기록(숙제, 색칠)은 Firebase에 있어서 다시 올려도 그대로 남아요.

## 회원 목록 보기

- **가입한 계정**: Firebase 콘솔 → Authentication → **사용자** 탭 (이메일, 가입일, 마지막 로그인)
- **닉네임 등 회원 정보**: Firebase 콘솔 → Firestore Database → `users` → (사람별 ID) → `profile` → `main`
  - `nickname`(닉네임), `email`, `joinedAt`(가입일), `lastSeen`(마지막으로 들어온 날)
- 비밀번호는 Firebase가 암호화해서 보관하기 때문에 관리자도 볼 수 없어요. 잊어버린 사람은 로그인 화면의 "비밀번호를 잊었어요"로 재설정 메일을 받으면 돼요.

## 다른 방법: Firebase Hosting으로 올리기 (명령어에 익숙하면)

Netlify 대신 Firebase에 같이 올릴 수도 있어요. 이 경우 6단계는 자동으로 돼요.

```bash
npm install -g firebase-tools
firebase login
cd site
firebase use --add        # 1단계에서 만든 프로젝트 선택
firebase deploy           # 사이트와 firestore.rules가 같이 올라가요
```

주소는 `https://프로젝트이름.web.app` 이 돼요.

## 알아두면 좋은 것

- **무료 한도**: Firestore 무료 요금제는 하루 읽기 5만 번, 쓰기 2만 번이에요. 친구 여럿이 매일 써도 넉넉해요.
- **내 이미지로 바꾸기**: 올린 사진은 작게 줄여서 각자 계정에 저장돼요.
- **로그인 없이 써보기**: `firebase-config.js`를 비워두면 로그인 없이 그 기기에만 저장하는 모드로 동작해요. (이때는 초대 코드도 필요 없어요)
- **검색 차단**: 사이트에 "검색엔진에 올리지 마세요" 표시(noindex)가 들어 있어서 구글 등에 잘 안 떠요. 다만 링크를 아는 사람은 열 수 있으니, 실제로 막는 건 초대 코드예요.
- **Google 로그인**: 구글로 처음 들어온 사람은 로그인 뒤에 초대 코드를 한 번 넣는 화면이 나와요.
- **잘못 색칠했을 때**: 색칠 직후 아래에 뜨는 **되돌리기**를 누르면 돼요.
- **화면 밝기**: 설정에서 시스템 / 밝게 / 어둡게를 고를 수 있어요.
- **카톡 미리보기 이미지**: `index.html`의 `og:image` 주소가 GitHub Pages 주소로 적혀 있어요. 다른 주소에 올렸다면 그 주소로 바꿔주세요.
- **저작권**: 캐릭터는 헌터×헌터를 따라 그린 팬아트예요. 친구끼리 쓰는 건 괜찮지만, 사이트를 널리 공개하거나 돈을 받으면 문제가 될 수 있어요. 그럴 땐 캐릭터를 오리지널로 바꾸는 게 안전해요.
